# Pothole Detection in VietNam

A deep learning project for detecting potholes on road surfaces in Vietnam using YOLO (You Only Look Once) architectures.

## Project Structure

```text
├── data/               # Dataset directory (ignored by git)
├── notebooks/          # Jupyter notebooks for training, testing and evaluation
├── .gitignore          # Git exclusion rules
├── LICENSE             # Project license (MIT License)
└── README.md           # Project documentation
```
